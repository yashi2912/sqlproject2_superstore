# Superstore Sales Analysis | SQL Project

## Overview
Analyzed Superstore dataset (9,994 orders) using PostgreSQL to find sales, profit & customer trends.

## Files
- `Sample - Superstore.csv` - Raw dataset
- `SUPER_STORE DATA.sql` - SQL queries

## Tools
PostgreSQL, pgAdmin, SQL

## Analysis Covered
- Total Sales, Profit, Region & Category Analysis
- Top Products & Customers
- Monthly Sales Trend & YoY Growth
- Loss Analysis & Discount Impact
- Top 3 Products per Category (RANK & Window Functions)

## Key Insight
West Region has max sales, Technology is most profitable, Furniture faces losses due to high discounts.
